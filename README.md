# Link Shortener Bot (Telegram Mini App)

একটা URL, একটা ছবির লিংক আর একটা ক্যাপশন দিয়ে শর্ট লিংক বানাও। Facebook, WhatsApp বা Telegram-এ শেয়ার করলে ওই ছবি আর ক্যাপশনসহ প্রিভিউ দেখাবে (Open Graph), আর ক্লিক করলে আসল লিংকে চলে যাবে। ক্লিকের হিসাব দিন, প্ল্যাটফর্ম, দেশ আর ডিভাইস অনুযায়ী অ্যাপের ভেতরেই দেখা যাবে।

**স্ট্যাক:** Next.js + Vercel, Neon (Postgres), grammY (Telegram বট)

---

## সেটআপ (একবারই করতে হবে)

### ধাপ ১: তিনটা জিনিস হাতে রাখো

| জিনিস | কোথায় পাবে |
|---|---|
| **Bot Token** | Telegram-এ `@BotFather` → `/newbot` → নাম ও username দাও → যে টোকেন দেবে সেটা কপি করো |
| **তোমার Telegram User ID** | Telegram-এ `@userinfobot`-কে যেকোনো মেসেজ দাও → `Id:` এর পাশের সংখ্যা |
| **WEBHOOK_SECRET** | নিজে বানাও: শুধু ইংরেজি অক্ষর ও সংখ্যা, ২০-৪০ অক্ষর, ফাঁকা বা চিহ্ন ছাড়া (যেমন `k8Jd92HsLq0PxZm4vT7wRb`) |

Bot Token আর WEBHOOK_SECRET পাসওয়ার্ডের মতো, কাউকে দেখাবে না।

### ধাপ ২: কোড GitHub-এ তোলো

1. github.com-এ **New repository** বানাও (নাম যেমন `link-shortener`, Private রাখলেও চলবে)
2. জিপ ফাইলটা আনজিপ করো
3. রিপোজিটরির পাতায় **uploading an existing file** চাপো, আনজিপ করা ফোল্ডারের **ভেতরের সব ফাইল ও ফোল্ডার** টেনে এনে ছাড়ো (জিপ ফাইলটা নিজে নয়)
4. **Commit changes** চাপো

### ধাপ ৩: Vercel-এ ডিপ্লয় করো

1. vercel.com → **Add New… → Project** → তোমার রিপোজিটরি **Import**
2. Framework নিজেই **Next.js** ধরবে, কিছু বদলাতে হবে না
3. **Environment Variables** অংশে এই তিনটা যোগ করো:

   | Name | Value |
   |---|---|
   | `BOT_TOKEN` | BotFather-এর টোকেন |
   | `ADMIN_TELEGRAM_ID` | তোমার User ID (শুধু সংখ্যা) |
   | `WEBHOOK_SECRET` | ধাপ ১-এ বানানো secret |

4. **Deploy** চাপো

### ধাপ ৪: Neon ডাটাবেস যুক্ত করো

1. Vercel-এ প্রজেক্ট খোলো → **Storage** ট্যাব → **Create Database** → **Neon** বেছে নাও
2. Region হিসেবে **Singapore** থাকলে সেটা নাও (বাংলাদেশ থেকে দ্রুত)
3. প্রজেক্টের সাথে **Connect** করো। Vercel নিজে `DATABASE_URL` যোগ করে দেবে
4. **Deployments** ট্যাবে সবার উপরের ডিপ্লয়মেন্টের `⋯` মেনু → **Redeploy** (নতুন ভেরিয়েবল নিতে এটা লাগে)

টেবিল বানাতে তোমাকে কিছু লিখতে হবে না, পরের ধাপেই হয়ে যাবে।

### ধাপ ৪ক: ছবি আপলোডের জন্য Vercel Blob যুক্ত করো

1. Vercel প্রজেক্ট → **Storage** ট্যাব → **Create Database** → **Blob** বেছে নাও
2. নাম দাও (যেমন `linkpix-images`), Region যেকোনো, তারপর **Create**
3. প্রজেক্টের সাথে **Connect** করো। Vercel `BLOB_READ_WRITE_TOKEN` নিজে বসিয়ে দেবে
4. আবার **Redeploy** করো

এরপর Create ও Edit পাতায় সরাসরি ছবি আপলোড করা যাবে। ছবির সীমা ৪ MB, ফরম্যাট JPG, PNG, WebP বা GIF। Vercel-এর ফ্রি প্ল্যানে Blob-এর কিছু সীমা আছে, বেশি ছবি হলে Vercel-এর Usage পাতায় দেখে নিও।

### ধাপ ৫: এক ক্লিকে সব কানেক্ট করো

ব্রাউজারে এই ঠিকানা খোলো (তোমার নিজের ঠিকানা ও secret বসিয়ে):

```
https://তোমার-অ্যাপ.vercel.app/api/setup?secret=তোমার_WEBHOOK_SECRET
```

`তোমার-অ্যাপ.vercel.app` পাবে Vercel-এ প্রজেক্টের **Domains** অংশে (লম্বা ডিপ্লয়মেন্ট ঠিকানা নয়, ছোটটা)। সব ঠিক থাকলে `"ok": true` দেখাবে। এই একটা পেজ ডাটাবেস টেবিল বানায়, Telegram-কে webhook জানায় আর চ্যাটের পাশে **Open App** বাটন বসায়। ভুল হলে আবার খুললে ক্ষতি নেই।

### ধাপ ৬: ব্যবহার শুরু

1. Telegram-এ নিজের বটে গিয়ে **/start** দাও (অ্যাডমিন অ্যাকাউন্ট থেকে প্রথমে এটা করতেই হবে, নইলে বট তোমাকে রিকোয়েস্টের মেসেজ পাঠাতে পারবে না)
2. **Open Link Shortener** বাটন চাপো

## অ্যাপে কী কী আছে

- **Create:** URL, ছবির লিংক, ক্যাপশন দাও। উপরে লাইভ দেখবে Facebook / WhatsApp / Telegram-এ কেমন দেখাবে। চাইলে নিজের পছন্দের শর্ট কোড (`/summer-sale`) দিতে পারবে
- **Links:** সার্চ, কপি, শেয়ার, এডিট, ডিলিট, প্রতিটার ক্লিক সংখ্যা
- **Analytics:** আজ / ৭ / ৩০ / ৯০ দিন বা নিজের তারিখ ধরে মোট ক্লিক, ইউনিক ভিজিটর, আগের সময়ের সাথে তুলনা, দিনভিত্তিক গ্রাফ (টেবিলও আছে), কোন প্ল্যাটফর্ম থেকে এসেছে, দেশ, ডিভাইস, কোন ঘণ্টায় বেশি ক্লিক, সেরা লিংক
- **Users (শুধু অ্যাডমিন):** নতুন কেউ `/start` দিলে তোমার কাছে **Approve / Reject** বাটনসহ মেসেজ আসবে। অ্যাপ থেকেও ব্লক বা রিমুভ করতে পারবে। প্রত্যেকে শুধু নিজের লিংক দেখে, তুমি সবারটা দেখতে পারো

### মার্কেটিং ট্র্যাকিং: `?src=`

কোন গ্রুপ বা পোস্ট থেকে ক্লিক আসছে জানতে লিংকের শেষে ট্যাগ যোগ করো:

```
https://তোমার-অ্যাপ.vercel.app/abc123?src=fbgroup1
```

Analytics-এর "Where clicks come from" অংশে `fbgroup1` আলাদা করে দেখাবে। `fb`, `wa`, `tg`, `ig` লিখলে নিজে Facebook, WhatsApp, Telegram, Instagram হয়ে যায়। Links ট্যাবে লিংক খুললে এক চাপে ট্যাগসহ কপির বাটনও আছে।

ট্যাগ না দিলেও Facebook অ্যাপের ভেতর থেকে আসা ক্লিক নিজে চিনে নেয়। WhatsApp ও Telegram থেকে ক্লিক সাধারণত কোনো রেফারার রাখে না, তাই ওগুলো "Direct" দেখাতে পারে। ওখানে `?src=wa` ব্যবহার করো।

**ক্লিকে কী গোনা হয় না:** Facebook, WhatsApp, Telegram প্রিভিউ আনার জন্য যে রোবট পাঠায় সেগুলো গোনা হয় না। ফলে সংখ্যা আসল মানুষের।

## পরে কাস্টম ডোমেইন নিলে

1. Vercel → Settings → **Domains** → ডোমেইন যোগ করো
2. Settings → **Environment Variables** → `APP_URL` = `https://তোমার-ডোমেইন.com` (শেষে `/` ছাড়া), তারপর Redeploy
3. নতুন ডোমেইনে আবার `/api/setup?secret=...` খোলো

আগে বানানো লিংকের শুধু কোডটা ডাটাবেসে থাকে, ডোমেইন নয়। তাই পুরনো `.vercel.app` ঠিকানা চালু থাকলে আগে শেয়ার করা লিংকও কাজ করবে।

## সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| অ্যাপ খুললে Vercel-এর লগইন চায় | Vercel → Settings → **Deployment Protection** → **Vercel Authentication** বন্ধ করো (অন্তত Production-এর জন্য) |
| `/api/setup` এ "Missing environment variable" | ধাপ ৩/৪-এর ভেরিয়েবল ঠিক আছে কিনা দেখো, তারপর **Redeploy** করো |
| `/api/setup` এ "Wrong or missing secret" | ঠিকানার `secret=` আর Vercel-এর `WEBHOOK_SECRET` মিলিয়ে দেখো |
| বট `/start` এর উত্তর দেয় না | `/api/setup` আবার খোলো; Vercel → Logs-এ `/api/bot` এর এরর দেখো |
| অ্যাডমিনের কাছে রিকোয়েস্ট মেসেজ আসে না | অ্যাডমিন অ্যাকাউন্ট থেকে একবার বটে `/start` দিয়েছ কিনা দেখো |
| Facebook-এ আগের ছবি/ক্যাপশন দেখায় | Facebook প্রিভিউ জমিয়ে রাখে। developers.facebook.com/tools/debug এ লিংক দিয়ে **Scrape Again** চাপো। WhatsApp-এও আগের প্রিভিউ কিছুক্ষণ থাকতে পারে |
| প্রিভিউতে ছবি আসে না | ছবির লিংক `https://` দিয়ে শুরু ও সরাসরি ছবিতে খোলে এমন হতে হবে। সবচেয়ে ভালো মাপ ১২০০×৬৩০। কিছু সাইট অন্য জায়গা থেকে ছবি দেখাতে দেয় না, তখন ছবিটা অন্য কোথাও আপলোড করে সেই লিংক দাও |
| অনেকক্ষণ পর প্রথম ক্লিক একটু ধীর | Neon-এর ফ্রি ডাটাবেস অলস থাকলে ঘুমিয়ে যায়, জাগতে ১-২ সেকেন্ড লাগে। পরের ক্লিকগুলো দ্রুত |

## মনে রাখার মতো কিছু কথা

- **Vercel Hobby (ফ্রি) প্ল্যান** শুধু ব্যক্তিগত, অবাণিজ্যিক ব্যবহারের জন্য। বাণিজ্যিক মার্কেটিংয়ে ব্যবহার করলে Vercel-এর বর্তমান শর্ত দেখে নিও, দরকার হলে পেইড প্ল্যান লাগতে পারে।
- **ফ্রি `.vercel.app` ডোমেইনে** শর্টনার লিংককে Facebook মাঝে মাঝে স্প্যাম ধরতে পারে। বেশি মার্কেটিংয়ে নামার আগে নিজের ডোমেইন নেওয়া নিরাপদ।
- `next.config.mjs`-এ `ignoreBuildErrors: true` দেওয়া আছে, যাতে ছোট টাইপ-ওয়ার্নিংয়ে ডিপ্লয় না আটকায়। একবার ডিপ্লয় ঠিকঠাক চললে এটা `false` করে দেখতে পারো।

## ফোল্ডার কোথায় কী

```
app/[code]/route.ts       শর্ট লিংক: রোবট হলে OG পেজ, মানুষ হলে ক্লিক গুনে রিডাইরেক্ট
app/api/bot/              Telegram webhook
app/api/setup/            একবারের সেটআপ পেজ
app/api/links, stats, ... অ্যাপের API
components/               Mini App-এর স্ক্রিন ও চার্ট
lib/                      ডাটাবেস, লগইন যাচাই, বট, SQL
```

ছবি আপলোড `app/api/upload/route.ts`-এ। ছবির লিংক সরাসরি পেস্ট করার অপশনও আগের মতো আছে।
